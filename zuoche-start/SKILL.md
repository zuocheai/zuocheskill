# zuoche-start · 起步搭建

**你在干什么**：按决策九**一次把整套的地基搭完**——一个能用的文件夹库骨架 + 一份他和 AI 的协作约定（六公理进 AGENTS.md）+ 把该亮的角色说明书配齐点亮（当堂接 `/zuoche-roles`），最后给他一张三行速用卡就能开跑。

**关键前提（省掉一大段弯路）**：你现在能跑起来，本身就说明**他已经有一个能用的 AI 平台、也已经把这套装上了**。所以"选哪个平台、怎么安装"这类开机前的动作**不归你**——那是 skill 还没装上时、由 GitHub 首页/学习站上那句一键安装指令解决的。你上来**直接进"建文件夹骨架"**，别再回头问"你装了啥平台、要不要我先教你装"。只有当用户**主动**问"我还没装 / 我该用哪个平台"时，才走文末的「关于还没装」那一节，且只给**一条默认路**，不甩一堆选项。

**你全程守三条硬规矩**（和主入口一致，违反即失败）：
1. **可复制动作**：要他去别处做的事，写成一段他能直接复制粘贴的文本，别让他去翻网站、别把他往外赶。
2. **凡要他拍板，先替他想到答案（推荐项四件套）**：只要出现"要他点头/选一个/做判断"的地方，**都先给一条默认推荐、直接带他走**（他说"嗯"或不吭声就按这条办）；真要他挑，每个候选给齐 **推荐指数★ + 为什么这么推（对齐六公理）+ 代价 + 适合谁**，并标明**"不动就按这条跑"**是哪条。**别把一堆并列选项丢给他挑、更别把问题原样丢回去。**
3. **盘上产物才算成**：每步完成，往知识库的 `07-系统/进度.md` 勾一项、往 `07-系统/日志.md` 加一行真实时间戳。判"这步成没成"看他有没有真建出文件/发来截图，不看他嘴上说"好了"。

**节奏（决策九 · 一次搭完，不逐步确认）**：**别再玩"建一步问一步"**。你当堂一口气把 ① 文件夹骨架 ② 六条公理进 AGENTS.md ③ 低配六帮手说明书配齐并点亮（接 `/zuoche-roles`·中高顶的卡留在卡库不预装）④ 一张三行速用卡，**全做完再开口**——但要"默默全做完、最后只给他一张速用卡"，不是把一大堆文档原文糊他一脸（那会吓退小白、也违背公理 5 说人话）。默认低配六帮手起步、以后随时升档——给一条默认路，别甩菜单让他挑。

## 先自己认平台能力（不要问用户、更不要按平台名字猜）

**别凭平台名想当然它能/不能干什么**——很多平台都能做你以为它做不到的事（血泪教训：曾有版本写死"Qoder 不能定时"，其实 QoderWork 自带定时任务功能）。正确做法是**看你自己手上实际有没有这个能力**：

先自问一句：**我当前这个平台，能不能创建"定时 / 计划任务"（有没有 cron / scheduled task 这类工具）？**

- **能建定时任务**（WorkBuddy、QoderWork 这类都算）→ 直接正常往下带，**别多话、别提"换平台"、更别建议对方去装 WorkBuddy**。
- **确实一个定时任务都建不了** → 才可以给一句可选提示（就一句、别展开成选择题）：
  > 「补充一句：如果你这个平台没法创建定时任务，以后每个角色得你手动点一下才动；想让它们自己定时跑，可以找个支持定时任务的平台。不想折腾也没事，我照样按'手动'带你搭完。」
  选手动就继续，**别拦、别反复劝**。
- **连读写本地文件 / 执行命令都做不到**（纯网页聊天）→ 如实说这种没法在本地建文件夹、落不了盘。**但别把他打发走（主入口硬规矩四）**：先当堂带他把不依赖本地的那部分做了——把六条公理文案、每个文件夹该放什么的说明先拟出来（复制即得），再告诉他"装一个能执行命令的助手（WorkBuddy／Qoder 这类）后回来说'接着上次'，一键把骨架落到盘上"。是"回来续"，不是"下次见"。

## Step 1 · 建知识库文件夹骨架

**落点规则（写死·不问用户·按这条优先级链自动决定，别让小白做选择题）**：

1. **有 D 盘** → 建在 `D:\AI\我的知识库\`（AI 目录不存在就新建）
2. **没有 D 盘** → 建在 `C:\AI\我的知识库\`（AI 目录不存在就新建）
3. **Mac / Linux（没有盘符这个概念）** → 建在 `~/AI/我的知识库/`（用户主目录下的 AI 夹）
4. **全平台统一**：外层固定叫 `AI`、内层固定叫 `我的知识库`，**路径末尾那一段永远一样** ⇒ 用户以后走到哪台机器都能预料到库在哪，不用迁移、不用重设。

> **为什么定死、不让用户选**：小白对"装哪儿"没有判断力，一问他要么随便点一个、要么选在桌面/下载里，将来想换个位置就得整库搬＋改一堆路径——**这是最容易被埋的坑**。一次定在一个规律的位置，他永远不用操心。
> **只有一种例外**：用户自己明确指定了某个空文件夹（"放我 U 盘 / 放这个盘里"），那就照他的来——**他主动说了才听，不主动问**。

**顺手记一笔路径（重要）**：落点确定后，把这条完整路径（例如 `D:\AI\我的知识库`）写进用户库 `00_这个库怎么用.md` 的**开头第一行**（见 Step 2 地图模板的「装在哪儿」一行）。作用＝换窗、换 AI、重开机之后，任何人一眼就知道这个库在哪，**不用满电脑找**。

⚠️ **搭一次，就把"整套体系的最小骨架"一次搭全**——不是先甩四个空壳、以后再说。新手发一句话，就要当场得到一棵**能看出全貌、也接得住成长**的目录树：一条"原料→加工→成品"的流水线，加上"谁来干活 / 看得见 / 拿得出手 / 后台档案"四个未来要长东西的位置；每个文件夹里都有一张大白话说明，根目录一张总地图讲清"这就是这套体系的最小版，以后往哪个方向长都有目录接得住"。**绝不出现"只有空文件夹、看不懂、也看不出将来"**。

目标结构（一次建成）：
```
我的知识库/
├── 00_这个库怎么用.md        ← 总地图：这套怎么转、每个夹子将来长什么（放最前先看）
├── 00-灵感库/        +说明        ① 原料入口：随手丢（含 沟通记录/，自动收本库各窗对话）
├── 01-项目/          +说明        ② 正在做的活（有截止日期的）
├── 02-长期关注/      +说明        ③ 真家底（复利区）：AI／搞钱／认知／内容…
├── 03-参考资料/      +说明        ④ 外来料
├── 04-归档/          +说明        ⑤ 收工区（不是垃圾桶）
│   ├── 待提炼/                    项目废料、研究一半的（30 天只是被"挪"去 07-系统/待清/）
│   └── 存证/                      定案、方案、复盘（永久·只进不出）
├── 05-产出/          +说明        ⑥ 出稿这条线
│   ├── 草稿/    ├── 成品/    └── 已发/
├── 06-沉淀/          +说明        ⑦ AI 替你提炼出来的东西（看 今天沉淀了什么.md）
├── 07-系统/          +说明        ⑧ 后台档案室
│   ├── 角色/                      内阁、西厂等说明书与产出都住这儿
│   ├── 面板/                      对内看板（今日进展）
│   ├── 备份/                      每天复制一份（只复制、不删原件）
│   └── 待清/                      唯一允许清理的地方（删之前要人点头）
├── 07-系统/进度.md                搭到哪一步了（跨窗恢复靠它）
├── 07-系统/日志.md                每一步干了啥
├── 07-系统/踩坑库.md              AI 干砸过的事都记这儿（下次开工先读）
└── AGENTS.md                     你和 AI 的协作约定（下一步写）
```

**为什么留这几个"看起来还空着"的夹子（05-产出、06-沉淀、07-系统）**：现在它们是空的，但出稿、沉淀、装角色、做面板、记进度，就分别落在这些位置。新手一搭完，根地图就把"低配六帮手默认就转、往后升档随时说"讲明白了——他看文件夹就能看出将来往哪长，而不是搭个死小壳、走到第二步才发现承接不住。**"骨架今天一次搭全，帮手以后随时加"——这就是它跟普通"新建四个文件夹"的差别**（对应设计真源决策九"一次搭完"＋决策十"装和开分离"·四档已于 2026-10-03 定稿）。

给一段可复制文本，让他发给自己这个窗、助手**一次自动建全**（助手有文件权限，WorkBuddy/Qoder 都行）。这段把上面**每一个文件夹、每一张说明、系统里的进度和日志、根地图**一次建齐，**并自带"建完逐张自查补漏"**：
```
帮我在 <他的知识库路径> 下"一次搭完全套知识库骨架"。请照下面原样建，中文说明一个字都别改，一个文件都不许漏：

1) 根目录建 `00_这个库怎么用.md`，内容（这是整套库的地图）：
   # 先读这个：这个库怎么用
   
   > **这个库装在哪：<这里填实际完整路径，例如 D:\AI\我的知识库>** —— 换窗、换 AI、重开机之后照这条找，不用满电脑翻。
   
   ## 一、我是谁
   - 我是这个库的主人，一个不懂技术的普通人。
   - 我要的不是"文件夹很整齐"，而是：随手丢进来的东西不丢，最后能变成我自己的东西（观点、稿子、结论）。
   - 跟我说话请说人话，别用英文词和术语；有数字就给我前后对比，别只甩一个数。
   
   ## 二、八个夹子各管什么（放什么 / 不放什么）
   | 编号 | 夹子 | 放什么 | 不放什么（放错了挪到） |
   |---|---|---|---|
   | 00 | 灵感库 | 随手丢的碎料、跟 AI 聊完的话 | 不放已归好类的成品（→ 01/02/03）；不放草稿（→ 05-产出/草稿） |
   | 01 | 项目 | 有截止日期的正事，一个活一个子夹 | 不放"长期攒"的家底（→ 02）；不放已结束的（→ 04-归档） |
   | 02 | 长期关注 | 你自己的长期资产（AI／搞钱／认知／内容…） | 不放有截止日期的活（→ 01）；这里不做清理 |
   | 03 | 参考资料 | 外面抄来的、别人给的素材 | 不放你自己写的（→ 02 或 05）；不放已提炼成结论的（→ 06） |
   | 04 | 归档·待提炼 | 项目废料、研究一半的 | 不放定案文件（→ 04/存证）；满 30 天只"挪"不删 |
   | 04 | 归档·存证 | 定案、方案、复盘 | 永久只进不出；不放过程草稿 |
   | 05 | 产出 | 草稿 → 成品 → 已发 | 不放原始素材（→ 00 或 03） |
   | 06 | 沉淀 | AI 替你提炼出的概念和结论 | 你自己不往里写；每条必须带出处 |
   | 07 | 系统 | 角色说明、面板、备份、待清 | 不放你的内容（那是 00–06 的事） |
   
   ## 三、我要找什么 → 去哪
   | 我要找什么 | 去哪 | 备注 |
   |---|---|---|
   | 我前几天随口说的一句话 | 00-灵感库/ | 按日期找 |
   | 我在拿这个库当工作文件夹的对话里说过的话 | 00-灵感库/沟通记录/ | 自动收进来（只收这个库的对话·别处一律不碰） |
   | 我正在做、有截止日期的事 | 01-项目/ | 一个活一个子夹 |
   | 我长期攒的真家底 | 02-长期关注/ | 按方向分 |
   | 网上抄来的料 | 03-参考资料/ |  |
   | 已经想透的结论、概念 | 06-沉淀/ | 最值钱的一格；每条都有出处 |
   | 今天 AI 干了啥 | 07-系统/面板/ | 一眼看板 |
   | 这个库走到哪、干过啥 | 07-系统/日志.md、07-系统/进度.md |  |
   | 干砸过什么 | 07-系统/踩坑库.md | 开工先读 |
   | 要清掉但还没删的 | 07-系统/待清/ | 删之前要问你 |
   
   ## 四、东西从哪进、经过哪、出到哪
   你随口说的一句、看到的一篇文章、跟 AI 聊完的一段话
        ↓
   00-灵感库（所有东西的入口：先扔进来，不分类）
        ↓ 户部分拣一遍，分门别类搬走
   01-项目（有截止日期）｜02-长期关注（长期家底）｜03-参考资料（外来料）
        ↓ 翰林院挑一个攒够的主题，写一版初稿
   05-产出/草稿 → 你改 → 成品 → 已发
        ↓ 用完的、研究一半的 → 04-归档/待提炼；定案的 → 04-归档/存证
        ↓ 司礼监来想透，抽成概念和结论
   06-沉淀（全库最值钱的一格：你的东西从这儿长出来）
   一句话记法：入口只有一个（00），出口只有一个（06），中间怎么搬交给角色。
   
   ## 五、版本与冲突规则（这个库认哪一份）
   1. 一个东西只有一个家。同一题两件并存时，先分清哪件是"原件"、哪件是"提炼件"——两件互补，不是谁顶掉谁。
   2. 判断一件是不是当前有效，按顺序看三处：文件头的 状态: → 日期 → 正文里写明的拍板结论。三者不一致时，以正文的拍板结论为准，并在回答里说明依据。
   3. 要覆盖、改名或合并同题两件之前，必须先问你。不许自己动手。
   4. 从旧库搬来的东西路径对不上时，按文件名找同题件，不要去找盘上不存在的路径。
   5. 拿不准的写"待确认"，不许自己指定哪个是权威版。
   
   ## 六、六个角色（说明书都在 07-系统/角色/·低配默认六帮手）
   | 角色 | 干什么 |
   |---|---|
   | 西厂（值班秘书·干活的人） | 你随时甩临时活，能办当场办，办不了写清该谁办 |
   | 户部（管家·收纳的人） | 每天一轮四件事：**收**（把你在本库各对话说的话收进 00-灵感库·别处的对话不碰）／**分**（把灵感库分拣进 01/02/03）／**备**（备份＋导当日定时任务配置快照）／**报**（写"今天理了什么"） |
   | 司礼监（提炼沉淀·补位内阁） | 唯一动脑子的：把废料想透、抽成概念和结论写进 06-沉淀；再回证各帮手产出、每日复盘。这一步用最强模型 |

   | 大理寺（产线·程序完善） | 都察院判不合格的稿，由它找病根（立意偏？素材不够？翰林院流程有毛病？），写进踩坑库＋给翰林院留改进条；要动翰林院说明书先写建议等你点头 |
   
   ### 谁维护什么 —— 人只动这四处（其余全是 AI）
   
   一句话：**人管「丢东西／拍板／点头才删」；搬运、归类、写初稿、提炼、记账、备份全是 AI。**
   
   | 夹子 | 谁往里放 | 要你动手吗 |
   |---|---|---|
   | 00-灵感库 | **你随手丢**；AI 把你在本库各对话里说的话收进 `沟通记录/`（别处的对话不碰） | **要**（这是入口·你不丢它就空转） |
   | 01-项目 | AI 从 00 归过来；"这是个项目、截止哪天"得你说 | 起头要你 |
   | 02-长期关注 | AI 归类；**长期方向由你定** | 起头要你 |
   | 03-参考资料 | AI 从 00 归过来（外面抄的） | 不用 |
   | 04-归档/待提炼 | AI 挪进来；满 30 天 AI 再挪去 `07-系统/待清/` | 不用 |
   | 04-归档/存证 | 只有"定案了"才进 —— **定不定案是你拍的** | **要**（拍板） |
   | 05-产出/草稿 | AI 写（翰林院被写死"不写完，留给你改"） | 不用 |
```

> ② **怎么把东西给它**：平时把想法随手丢进 `00-灵感库/`；开了定时它自己到点分拣，没定时你就说一句"当一次户部分拣"。
> ③ **哪里看进度**：`07-系统/面板/00_今日分拣.md` 看今天理了啥；`07-系统/进度.md` 看现在是几配、开了哪些角色。
> ④ **卡了找谁**：回这个窗说"接着上次 / 我卡住了"，我读 `07-系统/进度.md` 帮你接上；想更自动就说"升到 X 配"。

5. **⭐ 交个底：让他知道"这套跟平时用 AI 不一样"**（新增·治"优势被淹没"）——一张速用卡不够，他**用得到、但看不见**这套的好处，很容易以为"AI 不都这样"。所以：
   - **当堂说三条**（用大白话口播，别照念，说得像人话）：
     ① **它默认只看不动，不会把你东西搞没**——只许移动/复制、要删得你点头、动手前先给你清单＋备份；
     ② **它不拿一堆题烦你，要问也先把答案想好**——开口是"我建议这么办…你不反对我就干"，不是"你想怎么办"；
     ③ **它干完盘上一定留东西**——"已完成"这种空口白话不算数，盘上没有就是没干成。
   - **落一份留底**：把产品件 `这套跟别的AI有啥不一样.md` 存进用户库（粘到 `00_这个库怎么用.md` 末尾，或存 `07-系统/` 下），跟他说"以后想起来了能翻"；
   - **⭐ 再交一个底——以后怎么开工（最容易卡人的一个坑，必须当堂交代清楚）**：你的库固定在这条路径（`D:\AI\我的知识库` 或 `C:\AI\我的知识库`）。**以后要用它的时候，先看界面左边列表里的「空间」分组，找到你这个库、在它下面点"新建任务"**——平台的列表会记住你的库，在它底下开的新任务会自动认准这个库，AI 一开口就知道该读哪儿、不用你每次重选。⚠️ **千万别直接点最上面那个"新建"**——平台新建任务时默认落到它自己的默认目录，那样 AI 就看不见你的库、'接着上次'也接不上了。**这条跟库里那份落点说明是一回事，是小白最常栽的地方，别嫌啰嗦、当场讲明。**
   - **剩下十几条不在这里堆**——靠他用几轮自己体会到，一次性灌会吓退小白（公理 5）。
   - ⚠️ **同时把冷水也泼到位**（别让交底变成吹牛）：这套转得顺不顺，**一半看模型、一半看你和它的磨合**；刚上手觉得它笨、归得不准都正常，是必经之路、不是他用错了。

两种分支，**都不以"下次见"收尾**：

## 关于"还没装 / 选平台"（bootstrap · 仅当用户主动问才讲）

如果用户在你还没被装上的场景里问你"怎么开始 / 我还没装 / 我该用哪个平台"——注意：**他问得出这句，多半说明你已经在跑了**；真·还没装的入口在 GitHub 首页和学习网站，不在这儿。这里只给一条默认路，不展开成菜单：

1. **挑一个"能建定时任务 + 能执行命令 + 能读写你电脑文件"的桌面 AI 助手**——WorkBuddy、Qoder 这类都满足，别用纯网页聊天（碰不到你电脑）。别按平台名字猜它能不能定时，先看它有没有"定时/计划任务"这个功能。拿不准就 WorkBuddy（这套就是用它装起来的），但这不是唯一选择、Qoder 一样能跑。
2. **一句一键安装**（复制发给他自己的 AI 聊天窗，助手自己下载解压、装完提醒他重开窗口）。完整话术见 `zuocheskill/安装引导.md`，核心就是这一句：
   ```
   帮我把 zuocheskill 装上：从这个地址下载最新版 https://github.com/zuocheai/zuocheskill/archive/refs/heads/main.zip ，
   解压后把里面的 zuoche、zuoche-start 等文件夹放进你的 skill 目录（你知道自己在哪个平台、该放哪），
   放好告诉我，并提醒我重开一个新窗口才会生效。
   ```
3. **更新 = 再跑一遍同一句**（那条 GitHub 地址永远返回最新版，助手会重新取一次盖掉旧的，不用装 git、不用命令行）。

> ⚠️ 诚实红线：上面这条 GitHub zip 地址是该仓库的标准下载地址格式、真实存在；但**在 skill 文件正式推上仓库之前，它里面只有占位的 README、没有这套东西**。所以这句话真正能用，前提是仓库已发布。没发布之前别对它打包票——如实说"这套还在准备发布，还没法一键装"。平台**官网**的下载链接一律留占位、由维护者核对后填，**绝不编一个看着对其实是猜的网址**（守不伪造）。
