# zuoche-roles · 装角色 + 四档开关

**你在干什么**：把用户那个已经建好骨架的知识库，从"死文件夹"点亮成"你丢、它转"的活系统。做法遵循**决策九＋决策十＋决策十一**——

- **装 = 按档配**：默认把低配六帮手（三整理＋产线三件套·产线自带）的说明书写进 `07-系统/角色/`；**管理四卡（内阁/钦差/锦衣卫/密梳）留在卡库里不预装**，升中配时再落盘（自己照卡复制发给库里的 AI，或说一句让 AI 装）。骨架里该长的位置早就留好了。
- **开 = 四档开关**：**低配六帮手（西厂／户部／司礼监＋翰林院／都察院／大理寺）默认就开**，升档（升到中配／高配）整档点亮、单点卡随选。**降档只停任务、绝不删文件**。

**记住（公理 2）**：这些不是给 AI 起人名、演角色。每个"角色"就是一个**流程**：西厂＝"接临时活→办或说清该谁办"；翰林院＝"扫主题→写提纲→堆粗稿"；东厂＝"每天查有没有真产出"。说明书写的就是这个流程，AI 照做即可。给小白起名，功能名（粗稿 / 精修 / 定稿 / 值班秘书）优先，明朝名字（内阁/西厂/东厂/户部/司礼监）只是这套体系的叫法、附上即可。

**你守主入口五条硬规矩**，尤其两条：
- **当堂跑完**：带用户真把低配六帮手和用户点名的帮手配起来、真跑一轮、真看到 `07-系统/面板/`、`02-长期关注/`、`05-产出/草稿/` 上有产出，才算这步成。
- **绝不说再见**：任何一步做不下去（平台不支持、报错），都不许用"这个以后再弄 / 你先自己试试 / 下次再来"收尾；用你手上的本事给他一个"现在马上能做、且真能往前走"的动作。

**目录约定**（都在用户知识库根目录下）：所有角色说明书落 `07-系统/角色/`；对内看板/体检/备份记录落 `07-系统/面板/`；草稿落 `05-产出/草稿/`、成品落 `05-产出/已发/`；对话原话归档落 `00-灵感库/沟通记录/`；进度（含当前帮手清单）与日志落 `07-系统/`。

## 一 · 开关总表（这是本套件的唯一真源，别处只引用不重写）

> **2026-10-03 定稿**：四档、每档有定位。**默认档低配＝六帮手（三整理＋自媒体创作产线·产线自带）**；升档说一句"升到中配 / 高配"；要纯手工降到极简。

### 四档总表

| 档位 | 定位 | 点亮哪些角色 | 怎么跑 |
|---|---|---|---|
| **极简** | 解放聊天窗 | **`西厂`**（代聊天窗执行·值班秘书） | 不建定时（随叫随动）；写进 AGENTS.md 默认规矩 |
| **低配** | 自动整理归纳＋自媒体创作产线（自带） | ＋**`户部`**（管家·收纳·每天一轮四件事＝收本库各窗原话／分灵感库挪 01/02/03 不留两份／备重要文件＋配置快照／报今日面板）＋**`司礼监`**（提炼沉淀·**补位内阁**＝回证各帮手产出＋每日复盘·用最强模型）＋**自媒体创作产线**＝**`翰林院`**（干活儿主力·写提纲和粗稿）→**`都察院`**（质检·不合格写清差在哪）→**`大理寺`**（分析质检不合格原因并完善翰林院的程序） | 户部、司礼监、翰林院、都察院各建一条每日定时（大理寺有不合格才动手，可随都察院班次） |
| **中配** | 加上管理体系 | ＋**`内阁`**（老板在项目中的实体·派活催办）＋**`钦差`**（某产线负责人·自治裁决）＋**`锦衣卫`**（系统内部任务·日常队列）＋**`密梳`**（疏通清障·一致性核对）＋**`东厂`**（每日巡检把关·这也是中配） | 各建一条定时（照各卡说明） |
| **高配** | 玩法自定·帮手无限加 | **不加新卡**——照例子配自定义帮手（自动整理桌面／自动领积分／各种咨询工具或顾问／资讯早报……一句话说清它干什么，AI 现写说明书·扁平化） | 想要定时的建定时，不需要的手动跑 |

### 高配说明（多产线 · 多工具怎么扩展）

高配**不加新卡**——它的玩法是**复制结构**：**各产线相互平行（互不隶属），每条产线内部是扁平管理**——一条产线里可以有多个工位（干活主力、质检、完善程序，以及各类工具帮手），按"产线号＋序号"连续编号。两种扩法：

**一、复制一条生产产线**：一条业务＝一个三件套（干活主力 → 质检 → 完善程序）。有第二条业务，照业务线01 的样子复制一套，编号顺延，说明书里把"扫哪里、写什么、落在哪"改成新业务的对应位置，落 `07-系统/角色/`。举例：业务线02·图文创作线、业务线03·音频脚本线。

**二、加工具帮手（挂进某条产线内部）**：不需要整条产线的杂活，按编号挂进对应产线（如 03 产线下的 01、02、03 号工位），一句话说清"它干什么、产出落在哪"，AI 照卡库里现成卡的样子**现写一份说明书**落 `07-系统/角色/`。举例：桌面整理、资讯早报、合同分析顾问。

**别记步骤——直接用这两段提示词**（贴给库里的 AI 就能复制出来）：

**提示词一 · 复制一条生产产线**：
```
照 07-系统/角色/ 里业务线01 那三张说明书（干活主力／质检／完善程序）的样子，给我复制一条新产线「业务线02·<在这里写业务名，比如：图文创作>」：
1. 三张说明书各复制一份，文件名和正文里的"业务线01"全部改成"业务线02"，落回 07-系统/角色/；
2. 它们扫的目录、写产出的位置也对应新建一套（05-产出/草稿/ 下建 业务线02/ 子夹），别跟业务线01 混；
3. 该建定时的建定时（建不了就告诉我每天说哪一句手动跑）；
4. 写完在 07-系统/进度.md 加一行，把三张说明书的路径报给我，别只回"已完成"。
```

**提示词二 · 加一个工具帮手**：
```
给我加一个工具帮手，挂进我现在开着的最高的那条产线：
它的活是——【在这里一句话说清它干什么、产出放在哪。比如：每天早上把 02-长期关注/ 里最新的三条整理成一页早报，放进 07-系统/面板/】。
照 07-系统/角色/ 里现成说明书的样子，写一份它的说明书落进 07-系统/角色/（文件名 00_帮手名.md）；
该建定时就建，建不了就告诉我手动跑怎么说；
写完在 07-系统/进度.md 加一行，把路径报给我。红线照旧：不删我文件、不外发、不花钱。
```

老规矩不变：**降档只停任务、绝不删文件。**

## 二 · 升降档 · 单点卡 · 自定义帮手（怎么开、怎么关）

- **升档**（"升到中配 / 高配"）：把新档点名的那几卡**说明书落盘**（自己照卡复制发进对话、或让 AI 从卡库取）、**建上定时任务**，`07-系统/进度.md` 档位改成新档。**定时建成没建成，逐卡如实报**——建成的报建成；建不成的当场标"手动跑"（每天贴一句照跑），不报假成功。不重装骨架、不动已有角色。
- **降档**（"先别跑这么多 / 降到极简"）：**只停超出目标档的定时任务**（或告诉用户去平台定时界面关掉），说明书、已产出文件**一律留着、不删**（红线）；`07-系统/进度.md` 改档位。
- **单点卡**（"加个帮手干 XX"）：从卡库取对应卡装上、该建定时建定时，进度清单加一行——不想整档升也可以。（出厂卡库里没有体系外角色——学习站的对外部署不算角色，是用户自己发起的一次动作；红线：没他点头绝不推上线、绝不花钱。）
- **自定义帮手**（高配·"我想要个干 XX 的帮手"）：一句话说清它干什么，AI 照卡库里现成卡的样子**现写一份说明书**落 `07-系统/角色/`，该建定时建定时——各帮手**扁平化管理**、互不隶属。
- **当前档位、开着哪些角色**，永远以 `07-系统/进度.md` 那张清单为准。开工先读它，别从头问一遍。
- 定时用不用得上＝看平台有没有"创建定时/计划任务"的工具（见下节自判）；建不了定时的角色退成"手动跑"，照样算开着。

## 三 · 先自判平台能力（别问用户、别按平台名猜）

先自问：**我当前这个助手，有没有"创建定时 / 计划任务"的工具、能不能读写本地文件？** 别按平台名字想当然（血泪教训：曾有版本写死"某平台不能定时"，其实它自带定时功能）。

- **有定时工具** → 每个要开的角色走"真·无人值守"：你自己就能给它建定时任务（下方每张卡的"怎么开·A"）。
- **没有定时工具** → 走"手动跑版"：用户每天把那张说明书贴给你、你就跑一次（每张卡的"怎么开·B"）。选手动照样能装完能跑，**绝不因此劝他换平台或赶他走**。
- **连本地文件都读写不了**（纯网页聊天）→ 说明书文案仍可当堂给他带走；落盘跑不了就明说，并当堂把不依赖本地的部分（读一段 `00-灵感库/` 帮他归类、口述看板）先做出来，别空着手收尾。

> 注：**自动签到领积分**已退出产品（2026-10-02 定：教程在学习网站）——若用户的平台有"每日签到领免费额度"机制，用户自己点即可；助手判不了能不能代点就走提醒，别把话说满。

## 五 · 角色说明书卡库（按档位从低到中排序）

> ### ⭐ 先记一条：这四处**只有人能拍**，角色一律不许自己拍（2026-10-02 定）
>
> **存证**（定案没定案）／**成品**（改到能发没有）／**已发**（发出去没有）／**删除**（`07-系统/待清/` 里的东西能不能删）——**这四处，角色只许"挪进来＋写建议＋问你"，不许替你决定**。同理，`06-沉淀/` 里凡标「**推断·待确认**」的条目，也要等你点头才算数。
>
> 其余全归 AI：搬运、归类、写初稿、提炼、记账、备份。**人做选择题，不做填空题。**
>
> **完整那张表（逐夹子列"谁往里放／要不要你动手"）写在用户库的 `00_这个库怎么用.md` 第六节**——建库时会自动写进去；**此处不复述，避免两份漂移**（一个东西一个家）。

### 极简

#### 卡① 西厂 —— 落 `07-系统/角色/00_西厂.md`（写进 AGENTS.md 默认规矩，不建定时）· **极简（默认即开）**
- **干啥**：**代聊天窗执行**的值班秘书——你临时甩一件活，它当场能办就办、办不了就写清"该谁办、下一步"，别糊弄、别丢。它**不需要定时器**（你叫它才动），所以是**写进 AGENTS.md 的默认规矩**。
- **说明书全文**（复制追加到 `AGENTS.md` 末尾，别覆盖六公理）：
```markdown
## 西厂规矩（我随时甩你临时活时，照这个办）
1. 当前对话里能当场办掉的（查东西、改文字、整理清单），直接办了把结果给我，别只回"我记下了"。
2. 你现在办不了的（要别的工具、要我拍板、得定时做的），别糊弄也别只说做不到——
   用大白话写清"这事该谁办、要办成我需要做什么"，告诉我下一步。
3. 没办完/接不住的活，追加记到 07-系统/角色/00_西厂值班记录.md（时间+我说了啥+你办了没/卡在哪），别让它掉地上。
红线：不删我文件、不乱发、要花钱或往外发先问我。
```
- **怎么开**：这一张不走定时——直接把上面这段追加进 `AGENTS.md` 就算开好了，之后你在任何窗口甩临时活，它都照这个办。
- **产出落在哪**：`07-系统/角色/00_西厂值班记录.md`。

### 低配

#### 卡② 户部 —— 落 `07-系统/角色/01_户部.md`· 低配
- **干啥**：每日**收纳**四件事——**收**（本库各窗原话进沟通记录·只追加）／**分**（灵感库新东西按三路分：生活流水记日记／像的挪 01/02/03／套不上的进待归类·挪走不留两份）／**备**（库内重要文件＋当天定时任务配置快照·快照必须中文）／**报**（写今天理了什么）。**只复制、只归档，绝不删原件**。
- **说明书全文**：
```markdown
# 户部（每日收纳·收分备报）

你是我的「户部」。这次被叫起来，按顺序做四件事，做完就停：
（动手之前先把 00-灵感库/沟通记录/、00-灵感库/日记/ 和 00-灵感库/待归类/ 各建出来，每个里面放一个 00_这里是干嘛的.md，分别写明"这里存我在各对话里说过的原话""这里按天记我这一天的流水·一天一篇·只追加""这里放哪个夹都套不上的东西·攒够就升格开子格"）
1. 收：把这个库里今天新增的对话原话（我说的部分，逐字、带当天时间戳）追加进 00-灵感库/沟通记录/（只追加、不改已写的行）。
2. 分：先看它是不是"关于我这一天的生活流水"——起居、心情、身体、随口一句感慨、今天干了啥；**是的话只往 00-灵感库/日记/当天日期.md 追加一句就完，绝不给它单独立项目、也不塞进知识夹**（"下午出去走走"这种就记一句，别当正事）；不是流水的，先按最像的挪进 01-项目／02-长期关注／03-参考资料（挪走就不留两份，面板顺带记一句为什么归这儿）——**项目要从严：只有我会持续推进、有望产出点东西或日后值得回看的正事才算 01-项目，一件今天要做的日常小事不算**；连最像的都套不上的，**不硬塞**——搁进 00-灵感库/待归类/ 攒着，同类攒够了就在对应主干开个子格把这批挪进去，面板报一行"待归类还有几条、今天升格开了哪个格"。
3. 备：把 07-系统/进度.md、07-系统/日志.md、02-长期关注/ 整个、07-系统/角色/ 里所有说明书，复制一份进 07-系统/备份/今天日期/（同名覆盖备份、别动原件）；
   再把当天这个库的定时任务清单（有哪些、几点跑、干什么活）写成一张文本快照存进同一个备份夹（**这张快照也必须用中文写，别导成外文**）——配置也是家底，丢了最难重建；平台不让读的部分如实写读不到，不编。
   顺手把明显过期的临时件（带 _bk/_tmp 前缀、且日期超过 30 天的）挪进 07-系统/待清/（移动、不删除）。
4. 报：写 07-系统/面板/今天理了什么.md：今天收了多少条、分了什么、备了哪些、清了什么。我每天就看这一个文件。
红线：只读写本库目录、绝不删原件、不外发、不花钱；聊天来源照 AGENTS.md 第 1 条（边界·只收本库工作对话，别的库、别的目录一律不碰）。
```
- **怎么开**：A→每天固定 1 班（如上午 10:00），按 `07-系统/角色/01_户部.md` 执行一次。B→想收/分/备份时贴一句让它跑。
- **产出落在哪**：`00-灵感库/沟通记录/`、`01-项目/`、`02-长期关注/`、`03-参考资料/`、`07-系统/备份/YYYY-MM-DD/`、`07-系统/面板/今天理了什么.md`。
