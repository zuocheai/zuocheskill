# zuocheskill

一套对话式引导工具。你在聊天框直接说一句「我要搭建知识库」，它就一步一步问你、
一步一步带你把整套 AI 知识库和内容产线搭起来——不用会写代码，也不用先懂该装什么。

**当前状态**：搭建中，主入口与子模块陆续落地。想看图文版教程，先去
[左车 AI 知识库 · 学习交流站](https://zuoche-kb.pages.dev/)。

## 它解决什么

很多人听过「该搭个知识库」，但不知从哪搭起、搭来干嘛、怎么持续用起来。
zuocheskill 把这件事拆成几次对话：先帮你把地基搭好，再按需往上加角色、
工作台、学习网站、写作流水线。每一步只问你当前该定的那一个决定。

## 怎么来的

这套方法来自左车自己长期踩坑沉淀的「左车 AI 知识库」运营法（内部代号明朝班子）。
本仓库是把这套方法做成新手能无痛上手的引导版。
